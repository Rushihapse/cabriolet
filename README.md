# Cabriolet Arch

Local website project for Cabriolet Arch. The current site copy, portfolio names, contact information, and founder profiles are adapted from PS Innovative Creation's public website; the Cabriolet Arch project identity and existing non-founder imagery are retained.

## Run locally

```bash
npm install
npm run dev
```

## Routes

- `/` - Home
- `/about` - About and leadership profiles
- `/services` - Consulting, design, liaisoning and construction services
- `/projects` - Portfolio
- `/projects/:slug` - Project detail
- `/studio` - Locations
- `/careers` - Careers
- `/contact` - Studio contact and enquiry form

The site includes a persistent light/dark theme control, cinematic hero video, responsive navigation, scroll reveals, and reduced-motion support. Existing project and general photography are retained; the founder portraits use the images published on the source site.
