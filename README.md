# Cabriolet Arch

A React and Vite website for the Cabriolet Arch architecture practice.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

Vercel can deploy this project with the Vite preset, `npm run build`, and `dist` as the output directory. The included `vercel.json` sends client-side routes back to the SPA entry point.

## Before launch

Project names, founder details, testimonials, metrics, phone number, and email are illustrative placeholders. Several portfolio images are loaded from crystalarch.in and the hero footage is served by Pexels. Replace demo details and use approved, properly licensed media before presenting this as a live business website.
